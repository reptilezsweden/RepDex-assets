# RepDex assets

Public image assets for [RepDex](https://repdex.worldofbits.com), served through jsDelivr.

- `Images/Pokemon - 256x256/Addressable Assets/`: Pokémon GO icons, synced nightly from
  [PokeMiners/pogo_assets](https://github.com/PokeMiners/pogo_assets) by `.github/workflows/sync-pokemon-assets.yml`.
- `Images/Types/`: type icons.

The images belong to their respective owners (Niantic, The Pokémon Company); this repo only mirrors them for the app.
